# Contributing

Pull requests are welcome: fixes, new behavior, match logs, test reports, design notes.

- Your code stays yours. It goes in under the project's license (GPL-3.0 for `src/`, AGPL-3.0 for `tools/`,
  CC BY-SA 4.0 for `doc/`), so nobody can close it later.
- Don't paste in X-Ray engine code or files from the game. If you bring code from another mod, keep its author's
  name and license next to it, as with `src/varka/illish/`.
- Test in game (see Installation in the [README](README.md)) and say in the pull request what you checked and what
  you didn't.
