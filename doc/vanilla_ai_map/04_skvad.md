# 04 — Правда про отряды: восемь стволов = восемь островов

Самое важное недоразумение, которое надо выбить из головы: **в бою отряд НЕ думает как
отряд.** «Squad» в X-Ray — это в основном оффлайн-бухгалтерия ALife. В онлайновом бою
каждый NPC — остров, крутящий свою петлю из файла 01.

---

## Что «сквад» реально даёт (и чего НЕ даёт)

```
   ✓ ДАЁТ (бухгалтерия):                    ✗ НЕ ДАЁТ (штаб):
   ─────────────────────────                ──────────────────────────
   • список членов (squad_members)          • общий тактический план
   • командир (commander_id)                • распределение ролей
   • общий враг (заметил один —             • «ты держи, я обхожу»
     подтягивается остальным)               • фланги, охваты, клещи
   • позиция отряда (squad.position,         • подавление + манёвр в связке
     для ALife-перемещения по карте)        • «не стреляйте все в одну точку»
   • выкрики (bark: «Вижу!», «Граната!»)    • перекрытие секторов сознательно
```

Итог: враг **шарится** (все узнают, что ты есть и примерно где), но **что с этим делать —
каждый решает сам, своим планнером, по своей копии бита.**

---

## Картинка: 4 бойца против тебя

```
                        ты (игрок)
                           •
             ╱      ╱      │      ╲      ╲
            ╱      ╱       │       ╲      ╲       каждая линия — независимый
       set_sight          │              set_sight   set_sight в ОДНУ И ТУ ЖЕ
          ↑        ↑       ↑       ↑        ↑         memory_position
        [NPC1]  [NPC2]  [NPC3]  [NPC4]
          │        │       │       │
          └────────┴───┬───┴───────┘
                       │  между NPC — НИКАКИХ связей.
                       │  Ни один не знает, куда целится сосед.
                       ▼
              общий только «враг = игрок, LKP = вон там»
```

Нет линий **между** бойцами — только общий факт врага сверху. Поэтому:

- Все четверо целятся в **одну точку** (твою LKP). Углы не поделены → у тебя всегда есть
  «мёртвый» угол, откуда накрыт не весь пик.
- Ломаешь LOS — **все четверо теряют тебя почти одновременно** (общий инфоповод → близкие
  таймеры). Никто не «остаётся смотреть, пока другой обходит».
- Никто не займёт позицию, чтобы **закрыть твой путь отхода** — это требует общего плана,
  которого нет.

## Почему тогда толпа иногда убивает?

Не тактикой, а **объёмом огня + дизайном уровня.** Восемь стволов, даже независимых,
кладут восемь потоков пуль в твою LKP. Если level designer расставил их по хорошим
smart_cover с перекрывающимися секторами — это ЧИТАЕТСЯ как «оборона», хотя это застывшая
геометрия расстановки, а не решение ИИ. Отойди на угол, который их точки не покрывают —
и «оборона» рассыпается, потому что **никто не переставится.**

```
   ВАНИЛЬНОЕ «давление числа»        ЧЕГО НЕТ (настоящее давление)
   ────────────────────────         ──────────────────────────────
   8 турелей в одну точку           8 секторов, поделённых так,
   + удачная расстановка            что у тебя нет безопасного окна
   = много входящих пуль            = каждый твой пик кем-то накрыт
   (обходится флангом)              (обход закрыт заранее)
```

Это ровно §ЧИСЛЕННОСТЬ КАК ТАКТИКА из VARKA: «числа давят не уроном, а закрытием окон».
Ваниль закрывать окна не умеет — некому раздавать сектора.

## Ранг и «именные» персонажи в отряде

- **Ранг** (novice/experienced/veteran/master) = набор числовых ручек: разброс пули,
  скорость набора видимости, порог реакции, иногда HP/мораль. **Поведение он не меняет.**
  Мастер и новичок делают ОДНО И ТО ЖЕ, мастер просто точнее и «видит» быстрее.
- **Именной уникум** (условный «Капитан Гавриленко») в ваниле = высокий ранг + крутая
  броня/ствол + уникальная моделька. **Его ИИ идентичен любому рядовому.** Он не командует,
  не координирует, не отдаёт приказов. «Легендарный и молчаливый» = ноль bark-логики +
  толстый HP-пул. Легенда живёт в голове игрока, не в коде.

Это прямая иллюстрация нашего тезиса: **believability нельзя купить статами.** Восемь
островов остаются восемью островами, даже если один из них в экзоскелете и с именем.

## Куда это ведёт нас

Наш мод бьёт ровно в этот разрыв двумя слоями (§АРХИТЕКТУРА ЯДРА):

```
   [ЗНАНИЕ]   одно общее belief-облако на отряд   ← varka_lkp (звено 1, готово)
   [РЕШЕНИЕ]  распределение ролей/лотов поверх     ← varka_lots (звено 2, начато)
```

Ваниль имеет только «общий факт врага» на уровне ЗНАНИЯ и **пустоту** на уровне РЕШЕНИЯ.
Мы даём знанию структуру (облако вместо бита) и достраиваем отсутствующий слой решения
(аукцион вместо восьми независимых жадностей).
