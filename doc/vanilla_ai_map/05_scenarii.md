# 05 — Три сценария: как ваниль отыграет их по шагам

Те же ситуации, что мы разбирали «как ХОТИМ». Теперь — **как будет в ваниле.** Каждый шаг
опирается на файлы 01–04: один бит памяти, планнер-лестница, боевой цикл, острова-без-штаба.

Читай контраст: слева «фикшн, который обещает ситуация», справа «что даст код».

---

## СЦЕНАРИЙ 1 — Кордон, элеватор
**Игрок:** одиночка, ранг «опытный». **Против:** сквад наёмников — 3 новичка + 1 опытный.

Наёмники по умолчанию — **C++-бой** (нет `combat_type`). Значит: smart_cover + стрельба в LKP.

```
   ШАГ 1. Обнаружение
   ─────────────────
   Ты входишь в конус FOV наёмника M1. Рейкаст: стены нет.
   M1 набирает видимость (быстрее/медленнее по своему рангу) → M1: best_enemy = ты.
   M1 барком «Вижу!» + общий враг шарится на сквад.
   → Через 1–2с у M2, M3, M4 тоже best_enemy = ты (по выкрику/по своему LOS/по звуку).

   ШАГ 2. Каждый сам занимает укрытие
   ──────────────────────────────────
        [M1 новичок]   [M2 новичок]   [M3 новичок]   [M4 опытный]
             │              │              │              │
      ближайший       ближайший       ближайший       ближайший
      smart_cover     smart_cover     smart_cover     smart_cover
             │              │              │              │
             └──────────────┴───► все set_sight в ТВОЮ LKP ◄──┴──────────┘
                                   (одна точка, четыре ствола)

   ШАГ 3. Огонь
   ───────────
   Новички: широкий разброс → пули веером, много мимо.
   Опытный M4: кучнее → реально опасен.
   Поведение всех четверых ИДЕНТИЧНО. Разница только в точности.

   ШАГ 4. Ты нырнул за опору элеватора (сломал LOS)
   ────────────────────────────────────────────────
   У всех memory_position = точка, где ты стоял. Таймер ещё жив.
   → все четверо жгут/смотрят в ПРИЗРАК (пустое место). Никто не обходит опору.

   ШАГ 5. Таймеры истекли
   ──────────────────────
   best_enemy = nil у каждого → post_combat_wait → поозирались у своих точек →
   вернулись на патруль. Твоё реальное укрытие в 3 метрах никто не проверил как команда.
```

| Ситуация обещает | Ваниль даёт |
|------------------|-------------|
| «сквад наёмников — организованные профи» | 4 независимые турели в твою LKP |
| «опытный командует новичками» | опытный просто точнее, никем не командует |
| «numbers должны задавить» | давят объёмом пуль; ломается одним углом |

**Как игрок это разбирает:** сломал LOS → выбил по одному из-за опоры. Классика.

## СЦЕНАРИЙ 2 — Южный блокпост
**Игрок:** бандит, ранг «профессионал». **Своих:** 3 (2 опытных + 1 мастер).
**Против:** 8 долговцев + Капитан Гавриленко (экзо), остальные ~50/50 опытные/ветераны.

Блокпост = smart_terrain с **camper/guard**-джобами. Большинство Долга — на camper-логике.

```
   ШАГ 1. Расстановка (ДО боя, задал level designer)
   ─────────────────────────────────────────────────
   8 долговцев сидят по своим guard/camper точкам, перекрывающим подходы.
   Гавриленко — тоже просто на точке. Его экзо = толстый HP, его ранг = точность.
   Его ИИ = ИИ рядового campера. Ни приказов, ни манёвра.

   ШАГ 2. Контакт
   ──────────────
   Твой сквад заходит. Первый увидевший долговец D1 → best_enemy, барк, враг шарится.
   Постепенно все 8 + твои 4 — в бою, КАЖДЫЙ САМ.

   ШАГ 3. Долг: 8 camper-турелей
   ─────────────────────────────
     [D1]  [D2]  [D3]  [D4]  [Гавриленко]  [D6]  [D7]  [D8]
      │     │     │     │         │          │     │     │
     hide_fire по best_enemy, каждый со своей точки, СХОДА НЕ ИДЁТ.
     Потерял из виду → look_around, точку держит.
     ┌──────────────────────────────────────────────────────────┐
     │ Выглядит как «оборонительная линия». По сути — 8 частных  │
     │ campers на удачно расставленных точках. Никто не           │
     │ переставится закрыть твой фланг: это требует штаба.        │
     └──────────────────────────────────────────────────────────┘

   ШАГ 4. Твой сквад: 4 острова (default C++-бой)
   ──────────────────────────────────────────────
     [ты]  [B1 опытный]  [B2 опытный]  [B3 мастер]
     Каждый сам: занять укрытие → жечь по своей LKP Долга.
     B3-мастер = кучнее всех, но так же не координируется с тобой.
     «Повезло с мастером» = +точность в этом стволе, не +тактика в сквад.

   ШАГ 5. Развязка
   ───────────────
   Статичная перестрелка. 8 против 4 + укрытия блокпоста = Долг реально давит ОБЪЁМОМ.
   Но давление ФИКСИРОВАННОЕ: атакуй с направления, которое camper-точки не держат —
   и «оборона» не отвечает манёвром, потому что каждый прибит к своей точке.
```

| Ситуация обещает | Ваниль даёт |
|------------------|-------------|
| «Гавриленко — гроза, легенда» | толстый HP + точность; ИИ = рядовой camper |
| «8 долговцев держат блокпост» | 8 приколоченных турелей + хорошая расстановка |
| «мастер в твоём сквадe = козырь» | +точность одного ствола, ноль командной игры |
| «оборона блокпоста» | геометрия level design, не решение ИИ |

**Как игрок это разбирает:** найди сектор, не покрытый campers, зайди оттуда — линия не
перестроится. Гавриленко опасен как HP-губка с точным стволом, не как тактик.

## СЦЕНАРИЙ 3 — Радар, лаборатория, коридор
**Игрок:** штурмует, время поджимает, прёт вперёд.
**Против:** коридорные монолитовцы, «откровенно тупые».

Монолит в лабах — обычно `combat_type = "monolith"` (прёт на LKP) либо camper-guard. Возьмём
monolith как показательный: 4 действия, `go_to_pos` на last-seen vertex.

```
   ГЕОМЕТРИЯ: узкий коридор. Монолитовцы по цепочке.

     ты →→→   [M1]      [M2]      [M3]      [M4]
     ═══════════════════════════════════════════════ (коридор, флангов нет)

   ШАГ 1. Пикаешь угол. M1 попадает в LOS первым.
          M1: best_enemy = ты. Остальные ЕЩЁ НЕ ВИДЯТ (стена/угол между вами).

   ШАГ 2. monolith-логика M1:
          далеко? → fight_far, и/или go_to_pos → идёт на твою LKP.
          В коридоре «идти на LKP» = ПЕРЕТЬ ПО ПРЯМОЙ ТЕБЕ В ПРИЦЕЛ.

   ШАГ 3. Ты валишь M1. Теперь в LOS попадает M2 (был за M1).
          M2 только СЕЙЧАС получает best_enemy. Повторяет то же: прёт на тебя.
          M2 не «мстит за M1», не знал о его смерти как о тактическом сигнале —
          просто его личный бит только что зажёгся.

   ШАГ 4. Цепочка скармливает себя тебе по одному:
          [M1†] → [M2†] → [M3†] → [M4†]
          Коридор + один-бит-на-каждого + ноль координации = тир.
```

**Почему «откровенно тупые» — это структурно, а не халтура:**
- Каждый реагирует **только на личный LOS** — задний не знает, что передний уже труп и
  уже стреляют (пока сам не увидит/не окажется в бою).
- `go_to_pos` тащит их **по прямой на твою позицию** — в коридоре это худшее из возможного.
- Численности нет: коридор физически не даёт развернуть 4 ствола, а перестроиться
  (отойти, подождать, встретить пачкой) — некому решить, штаба нет.
- Твоя спешка на них не влияет — у них нет модели твоей срочности; чистая LOS-реакция.

| Ситуация обещает | Ваниль даёт |
|------------------|-------------|
| «фанатики Монолита в лабах» | цепочка островов, кормящих себя по одному |
| «numbers в замкнутом пространстве» | коридор + go_to_pos = самоубийственный конвейер |
| «засада» | никакой засады — реакция строго по личному LOS |

## СВОДКА: один и тот же корень во всех трёх

```
   ┌──────────────────────────────────────────────────────────────┐
   │  ОДИН БИТ памяти (файл 01)                                    │
   │      → все целятся в одну LKP, стреляют в призрак, забывают   │
   │        по таймеру                                             │
   │  НЕТ слоя РЕШЕНИЯ у отряда (файл 04)                          │
   │      → нет флангов, секторов, перестроений; каждый — остров   │
   │  РАНГ/ИМЯ = статы, не поведение                               │
   │      → «легенда», «мастер», «профи» дают точность, не тактику │
   └──────────────────────────────────────────────────────────────┘
              это и есть три места, куда бьёт мод:
   облако вместо бита  ·  аукцион/роли вместо островов  ·  деградация в
                                                          мозг/глаза, не в руки
```

Ваниль не халтура — ваниль **честно ограничена входом и отсутствием слоя решения.**
Наши сценарии «как хотим» — это ровно достройка этих трёх дыр. Теперь видно, что именно
достраиваем и почему без облака (звено 1) и лотов/ролей (звено 2) картинка не сдвинется.
