## ГЛАВНАЯ КАРТИНА — стек одного NPC

Каждый NPC каждый кадр прогоняет **одну и ту же петлю** сверху вниз. Мир → чувства →
память → решение → тело → снова мир. Ничего «умного» между слоями нет — есть конвейер.

```
                         МИР (Зона)
                            │   свет · звук · геометрия · другие NPC · игрок
                            ▼
        ┌────────────────────────────────────────────┐
        │  ВОСПРИЯТИЕ  (C++ memory managers)          │  ✓ параметры в m_stalker.ltx
        │  visual: конус FOV + дальность + рейкаст LOS │     глаза
        │  sound:  событие выстрел/шаг/взрыв + радиус  │     уши
        │  hit:    попадание → направление удара      │     кожа
        └───────────────────┬────────────────────────┘
                            ▼
        ┌────────────────────────────────────────────┐
        │  ПАМЯТЬ = ОДИН БИТ на врага                 │  ✓ best_enemy()
        │  memory_position (LKP) + memory_time (когда)│     точка + таймстамп,
        │  распад по ТАЙМЕРУ, без конуса, без сомнения│     БЕЗ растекания
        │  таймер истёк → врага просто ЗАБЫЛ          │
        └───────────────────┬────────────────────────┘
                            ▼
        ┌────────────────────────────────────────────┐
        │  ПЛАННЕР  (GOAP, motivation_action_manager) │  ✓ выбирает 1 действие
        │  лестница приоритетов по world-properties:  │
        │  alife < combat < danger < anomaly ...      │
        └───────────────────┬────────────────────────┘
                            ▼
        ┌────────────────────────────────────────────┐
        │  ДЕЙСТВИЕ  (action.execute)                 │
        │  ⚠️ C++-бой (default)  ИЛИ  ✓ Lua-схема      │
        │  суть: «занять укрытие, стрелять в LKP»     │
        └───────────────────┬────────────────────────┘
                            ▼
        ┌────────────────────────────────────────────┐
        │  ТЕЛО  (атомарные глаголы)                  │  ✓ set_sight / set_item(fire)
        │  state_mgr состояния + методы движка        │     ноги · поза · оружие · взгляд
        └───────────────────┬────────────────────────┘
                            ▼
                     действие в Зоне  ─────► меняет мир ─────► петля сначала
```

## ЗОЛОТОЕ ПРАВИЛО ВАНИЛИ

> **Каждый NPC крутит эту петлю ОДИН, за себя.**
> Отряда как единого тактического разума в бою **НЕТ**. «Сквад» в онлайне — это
> бухгалтерия ALife (кто в группе, общий враг, выкрики), а не штаб. Восемь бойцов в
> бою = восемь независимых турелей, глядящих каждая в свою память. Отсюда всё:
> и «протагонист-байес», и то, что численность не давит тактикой, а только объёмом огня.

Это — корень, от которого мы отталкиваемся. Весь наш мод = «дать слоям ПАМЯТЬ и РЕШЕНИЕ,
которых у ванили нет»: облако вместо бита, аукцион вместо восьми островов.
